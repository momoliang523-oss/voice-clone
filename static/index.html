    把网站装进扣子(coze.cn)

    1. 让网站有公网 HTTPS 地址 —— 本机运行扣子访问不到,需要用内网穿透(推荐 cpolar,国内节点)或部署到服务器。
      cpolar http 8000 拿到形如 https://xxxx.cpolar.top 的域名。
    2. 配置域名并重启 —— 编辑项目里的 .env:
      PUBLIC_BASE_URL=https://xxxx.cpolar.top 然后重启网站。
    3. 下载插件包 —— 点击下方按钮,得到 voice-tts-plugin.json。
    4. 导入扣子 —— 扣子 → 资源库 → +资源 → 插件 → 「导入插件」→ 上传这个 JSON,验证通过后点「试运行」输入日语文本测试。
    5. 发布并使用 —— 发布插件 → 创建 Bot → 添加插件 → Bot 会调用 synthesize 工具合成语音,并把音频链接发给用户。
